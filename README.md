# PokeForge

> pokepaste lab — intercambio ciego de equipos

PokeForge es una herramienta para crear, compartir y comparar equipos de
Pokémon estilo *pokepaste*, con un modo de intercambio "ciego": subes tu
equipo y no ves el del rival hasta que ambos lo habéis hecho.

## ✨ Características

- 📋 Crea y edita pokepastes con sprites reales
- 🤝 Salas de intercambio ciego por código
- 📖 Pokédex integrada
- ⚙️ Relay propio (Cloudflare Workers) para sincronizar salas
- 🧮 *Próximamente:* calculadora integrada

## 🚀 Uso

1. Abre la web.
2. Pulsa **Crear sala y publicar** para subir tu equipo.
3. Pasa el código de sala a tu rival.
4. Cuando ambos suban su equipo, se revelan.
